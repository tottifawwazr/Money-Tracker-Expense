# 💰 WealthFlow

WealthFlow is a premium personal finance dashboard and smart expense tracker built using **React 19**, **TypeScript**, **Tailwind CSS**, and the **Google Gemini AI (Gemini 3 Flash)**. Featuring a sophisticated Glassmorphism interface, it provides instant financial analytics, interactive data visualizations via Recharts, and an intelligent AI financial advisor to deliver context-aware savings recommendations based on your spending patterns.

📂 **[GitHub Repository](https://github.com/tottifawwazr/Money-Tracker-Expense)**

---

## ✨ Features

- **Premium Glassmorphism UI:** Developed a premium personal finance dashboard featuring a sophisticated Glassmorphism interface with persistent dark/light mode synchronization using local storage.
- **AI Financial Advisor:** Integrated Google Gemini AI (Gemini 3 Flash) to engineer an intelligent financial advisor that provides real-time, context-aware savings recommendations based on user spending patterns.
- **Advanced Financial Analytics:** Architected a robust transaction management system with complex state logic to calculate instant financial analytics (Daily, Weekly, and Monthly insights).
- **Interactive Visualizations:** Engineered interactive data visualizations using Recharts to provide users with a clear breakdown of expense categories and monthly allocation shares.
- **React 19 & Type-Safe Architecture:** Optimized application performance by leveraging React 19 features and modular, type-safe TypeScript components to ensure seamless UI responsiveness.
- **Offline Data Persistence:** Implemented client-side data persistence to ensure user financial data remains secure and accessible for offline viewing.

## 🛠️ Tech Stack

- **Frontend Framework:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **AI Integration:** Google Gemini API (Gemini 3 Flash)
- **Data Visualization:** Recharts
- **State & Storage:** React Hooks & LocalStorage
